Remote Tandem Robots (RETRO): Remote Operations and Experiments on Robots Using the Cloud

Pari Shah · Eiden Garcia · Iyinoluwa Tugbobo
Mentor: Bhagirath Tallapragada  ·  Faculty Advisor: Dr. Ashwin Ashok

Affiliation

  • Georgia State University · REU Site: Smart and Autonomous Systems
  • National Science Foundation — Research Experiences for Undergraduates

Project Overview

RETRO is a proof-of-concept for a reliable cloud robotic system that blends individual robotic capabilities with real-time coordination for a shared mission. The system addresses communication challenges in cloud robotics that can obstruct coordination between remote robots — critical for applications such as search and rescue in disaster scenarios.

Technical Highlights

  • Hardware: NVIDIA Waveshare JetBot AI kit — Jetson Nano 2GB, 2 DC motors, 8MP camera (1280×720 px, 160° FOV), PiOLED display.
  • Object Detection: SSD MobileNet-v2 model with ArUco markers for target and grid perimeter identification.
  • System Architecture: Three verticals — Cloud Communication, Sensory Data Management, and Mission Coordination — synchronized through a central Linux cloud server.
  • Contribution: Developed and tested mission coordination logic and cloud-based framework for synchronized remote experimentation across multiple JetBots.
